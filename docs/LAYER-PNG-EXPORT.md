# 动画图层素材导出（提案验证原型）

**需要真机测试：电脑检查已通过，PNG 透明度、尺寸、位置与跨软件导入尚未验收。**

## 用途与输出约定

面向动画分件制作：把当前画面各颜料图层一次导出为 PNG，并打包到一个 ZIP。
这不是时间轴 PNG 帧序列，也不是把所有层叠在一起的单张截图。

- 每张 PNG 保持原画布尺寸与原点，不裁边、不缩放、不合并其他图层；透明像素保留。
- 使用原始颜料像素，不烘焙图层不透明度、混合模式、继承透明度、剪切关系或附属蒙版。
  因此按普通混合叠回 PNG 不保证与工程合成画面相同；它们适合作为待重新合成的动画素材。
- 文件名为引擎图层序号加安全化图层名。序号保证同名图层不覆盖，组内名称不作为文件系统路径。
- `layers.json` 保存尺寸、当前帧、图层名、稳定 ID（字符串）、索引、父级、层级、显隐、
  不透明度、混合模式与剪切/继承标志。兄弟层按从下到上的原生顺序，父节点在子节点前。
- 默认包含隐藏图层，可以关闭；关闭时也排除隐藏父组内的图层。
- 组仅保留结构，不再输出整组图片。填充、调整、克隆、描边、蒙版、实时 3D 等其他节点
  暂不输出 PNG，清单记录 `omission`，界面预先说明范围，完成提示报告未导出数量。
  空颜料图层仍输出同尺寸透明 PNG，避免素材与层索引错位。

## 实现与影响面

导出页增加独立可选操作，使用现有 `renderLayerCanvas`，不改 JNI/C++ 或录制协议。
导出前暂停动画；读取图层元信息、当前帧、逐层渲染和 ZIP 编码放在同一个引擎 Handler 操作里，
防止导出过程中排队的绘画/换帧/切工程操作混入不同状态。
只复用一张导出专用 Bitmap，不写 UI 已发布位图，不切图层显隐、选中状态，不产生撤销命令。
ZIP 完成后用独立短时 I/O 线程写入用户选择的 SAF 文档，避免在 UI 线程复制大文件。

取消通过原子标记，在层之间及复制缓冲区之间检查；单次原生渲染或 PNG 编码不能立即中断。
失败/取消清理临时 ZIP，并尝试删除本次 CreateDocument 创建的目标；提供方不支持删除时提示用户检查。
点击取消、在进度窗口按返回或 ViewModel 销毁会请求取消；退到后台允许任务继续。
系统强杀仍可能遗留临时文件。

渲染器另有全尺寸 QImage 分配，逐层处理并不等于常量小内存。
第一版上限为 16,777,216 像素，超过时拒绝导出，不静默降低分辨率；捕获内存不足并提示处理。
导出占用引擎队列期间不能继续画画，界面显示进度和取消。该取舍需 RFC 评审。

## 手测流程

测试包使用独立包名 `com.reverie.paint.layerexporttest`，可与正式版共存；应用名称相同，
可在应用信息中用包名或 `1.6.0-test` 版本号区分。请用测试工程验证。

1. 在独立测试包中新建 1024×1024 作品，创建三个普通图层，分别在左上、中心、右下画不同颜色。
   将两个图层设成同名，再将一个设为隐藏。
2. 打开绘画页设置中的“导出”，找到“动画图层素材”，勾选“包含隐藏图层”，导出 ZIP。
3. 解压：每个普通图层都应有独立 PNG；名字相同也不覆盖；尺寸全部为 1024×1024。
   单张图只含本层笔迹、其余区域透明。导入支持分层的动画软件，原点对齐后位置不漂移。
4. 取消“包含隐藏图层”再导出，隐藏层应不生成 PNG。把一个可见层放进隐藏组后再次验证。
5. 增加空颜料层，确认会输出透明 PNG。增加填充/调整层，确认不会静默当作已导出，
   `layers.json` 对应项应无 file、带 omission，完成提示数量正确。
6. 将普通层不透明度设为 50%、混合设为正片叠底：PNG 保留原像素，
   清单记录 opacity/blendMode；导出不能改变工程状态、当前选层或撤销栈。
7. 动画工程停在不同帧分别导出，确认素材属于所选当前帧且无洋葱皮。
8. 多层较大画布导出中取消、保存到不可写位置、横竖屏切换，检查没有卡住或报告虚假成功。
   超过像素上限时应提示调整副本，不能自动缩小素材。

JVM 用例验证规划、命名、层级过滤、清单、真实 ZIP 写入与失败传播，不替代 Android 原生像素验证。
在 RFC 达成共识和真机验证完成前，本实现仅作为独立分支上的提案验证原型，不作为已完成合入的功能。
